# Vision Simulator Example (Vite + React)

This example app consumes the local `@vega-tek-hub/vision-simulator-v2` package.

## Setup

From the repo root:

```bash
yarn --cwd example install
```

Build the library (required after changes to the package):

```bash
yarn build:lib
```

Start the example app:

```bash
yarn --cwd example dev
```
