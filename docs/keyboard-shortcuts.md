# Keyboard Shortcuts

> Note: The shortcut handler is currently disabled in the editor (`useEditorShortcuts` is invoked with `enabled: false`). Flip it to `true` to activate these bindings.

## General

- `Esc` - Cancel current action / close transient UI
- `Cmd/Ctrl + Z` - Undo
- `Cmd/Ctrl + Shift + Z` - Redo
- `Cmd/Ctrl + K` - Search location (Map mode only)
- `Cmd/Ctrl + Shift + A` - Open Areas panel
- `Cmd/Ctrl + Shift + D` - Open Devices panel

## Tools

- `V` - Select tool
- `H` - Hand tool
- `A` - Draw Area
- `W` - Draw Wall (requires an area)
- `D` - Place Camera (requires an area)
- `P` - Place Person (requires an area)

## Shape Modes (when Draw Shape is active)

- `R` - Rectangle
- `C` - Circle
- `T` - Triangle
- `L` - Line
