# Developer Setup

## Requirements

- Node.js 18+ (or the project's supported runtime)
- Yarn (required by project conventions)

## Install

```bash
yarn install
```

## Environment Variables

Create a `.env` file with a Mapbox token:

```
VITE_MAPBOX_TOKEN=your_token_here
```

## Run

```bash
yarn dev
```

## Build

```bash
yarn build
```

## Lint

```bash
yarn lint
```
