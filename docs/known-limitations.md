# Known Limitations

- **Recording overlays**: Timestamp burn-in and camera name overlays are optional in the plan and not currently implemented.
- **Recording quality presets**: 720p/1080p/4K selection is not yet exposed.
- **Snapshot overlays**: Optional include/exclude overlays is not implemented.
- **Snapshot annotations**: Quick annotation mode is not implemented.
- **Bundle export**: Listed as 'soon' and disabled in the Export dropdown.
- **Keyboard shortcuts**: Wired in code but disabled by default (see `docs/keyboard-shortcuts.md`).
- **Scene Image export**: Requires Map mode and a valid Mapbox token; export will fail if the map is not initialized.
