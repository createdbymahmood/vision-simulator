# Advanced Operation

This guide covers deeper simulator usage without developer-only topics. For camera PTZ operation, select a camera and use the PTZ controls in the properties panel or the floating PTZ panel in Preview. Arrow keys adjust pan and tilt, and plus/minus adjusts zoom. Watch the FOV wedge and collision overlays update immediately.

For radar operations, use the radar panel to select people or cameras, toggle grid or trails through the context menu, and zoom or pan the radar view for dense scenes. Ping effects help locate selected people quickly.

For camera feeds, adjust the grid size to 2x2, 3x3, or 4x4 and use detection counts to validate coverage. If performance drops, reduce the feed count or close the panel temporarily.

For map style and search, switch map styles in Map Mode to match your environment and use Search Location to quickly reposition the map.

Undo and redo are available for all creation and editing actions. Continuous gestures such as dragging or resizing are stored as a single history entry.

Recording is best started before major PTZ changes or focus shifts. Snapshots capture a single high-resolution frame when you need a quick still image.

Planned features to watch include Preview 2D top-down mode, real device streaming in feed tiles, and real radar live detections in 3D.
